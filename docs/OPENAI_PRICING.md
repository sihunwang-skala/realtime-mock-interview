# OpenAI API 가격과 가성비 (2026-11-19 조회)

출처: OpenAI 공식 가격 페이지 https://developers.openai.com/api/docs/pricing (표준 요금, 입력 27만 토큰 이하 기준).
참고: 가격 정리 블로그 중 일부는 값이 달랐다(예: gpt-6.2-astra $10/$50). 공식 페이지 값을 사용했다. 가격은 바뀔 수 있다.

## 텍스트 모델 (1백만 토큰당 USD)
| 모델 | 입력 | 캐시 입력 | 출력 | 질문 품질(T8, 5점) | 첫 토큰(T8) |
|---|---|---|---|---|---|
| gpt-6-luna | 0.10 | 0.01 | 0.50 | 4.75 | 1.19s |
| gpt-6.1-terra | 1.00 | 0.05 | 5.00 | 5.00 | 0.97s |
| gpt-6.2-sol | 2.00 | 0.10 | 10.00 | 4.92 | 0.90s |
| gpt-6.2-astra | 8.00 | 0.40 | 40.00 | 4.92 | 1.66s |
| gpt-5.4-nano | 0.20 | 0.02 | 1.25 | - | - |
| gpt-5.4-mini | 0.75 | 0.075 | 4.50 | - | - |

질문 1,000개 생성 비용(질문당 입력 700 + 출력 150 토큰 가정): luna ≈ $0.15, terra ≈ $1.45, sol ≈ $2.9, astra ≈ $11.6.
**가성비 선택: gpt-6-luna** (품질 4.75, terra 대비 1/10 가격). 품질 최우선이면 gpt-6.1-terra. astra는 가장 비싸고 느린데 품질 이득이 없다.

## 실시간 음성 모델 (1백만 토큰당 USD)
| 모델 | 음성 입력 | 음성 출력 | 텍스트 입력 | 텍스트 출력 | 응답 지연 P50(T9) | 품질(T9) |
|---|---|---|---|---|---|---|
| gpt-realtime-2.1-mini | 10 | 20 | 0.60 | 2.40 | 1.69s | 4.08 |
| gpt-realtime-2 | 32 | 64 | 4.00 | 24.00 | 1.80s | 4.33 |
| gpt-realtime-2.1 | 32 | 64 | 4.00 | 24.00 | 2.22s | 4.67 |

**가성비 선택: gpt-realtime-2.1-mini** (3배 저렴, 가장 빠름, 품질은 조금 낮음).

## 지금까지 사용한 비용 (상한 추정)
호출마다 입력 1,000 + 출력 400 토큰(추론 토큰 포함)을 가정하고 단가를 곱한 값: 약 **$0.5 이하**. 실제 금액은 OpenAI 대시보드 Usage에서 확인할 것.
